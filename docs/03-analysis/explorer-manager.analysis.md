# Explorer Manager 요구사항 대응과 검증

2026-10-21 · v1.0.0

사용자의 12개 기능 요구사항에 대한 구현 대응은 12/12이다. 하드웨어에서 제공하지 않는 센서와 운영 장비 인수 시험은 별도 조건이며, 기능 구현률과 장비 지원률을 혼합하지 않는다.

## 요구사항 대응

| 요구사항 | 구현 | 검증 근거 |
|---|---|---|
| N개 드라이브 | Volume GUID/serial 식별, 볼륨별 다중 루트와 정책, 전역 작업 조정 | 볼륨/정책 검증, 연결 해제 UI 식별 유지 |
| 용량과 기간 기반 삭제 | 3가지 임계값 모드, 수정/생성 시각, 전체 후보 정렬 | 임계값 경계·기간 경계·루트 간 정렬 시험 |
| 오래된 순서와 공간 확보 시 중단 | 삭제 전후·복사 후 재측정, 완료 목표에서 다음 항목 중단 | 전역 정렬·항목별 중단·복사 중 외부 공간 확보 시험 |
| 백그라운드 | ServiceBase, 부팅 시작, UI 독립, 중복 호스트 차단 | Windows 서비스 설치·기동·IPC·제거 시험 |
| CPU·RAM·디스크 자원 | PDH, 메모리 API, 센서 호스트, 장치별 그래프와 품질 표시 | PDH 두 표본 CPU 수집, WPF 렌더, 실제 센서는 장비별 확인 |
| 삭제 이력 | 선행 저널, 항목·폴더·배치 집계, 논리 크기와 관측 순변화, CSV | 저널 장애·재시작·집계·검색 시험 |
| 잠금 스킵·알람 | 오류 분류, 작업 계속 진행, 알람 DB와 사용자 팝업 | 실제 배타 잠금과 가짜 잠금 조정 시험 |
| 강제 종료 후 삭제 확인 | 허용 앱, 소유 SID/세션/PID/시작 시각, 일회용 티켓, 재검증 | 변경된 프로세스 식별 거부와 소유한 테스트 자식 프로세스 종료 |
| RAM 1GB 복구 | 고정 블록 풀, 전역 1GiB 예산, SHA-256, FIFO, pin | 한도·병렬 예약·퇴출·취소·실제 파일/폴더 복구 시험 |
| HDD 이상 로깅 | 지속 지연·정체·오류 증가·온도·Windows 저장장치 이벤트 | 지속 규칙·PDH·알람 저장; 실제 오류/온도는 현장 확인 |
| WPF/net48/MVVM | Domain/Application/Infrastructure/Contracts/Client/Presentation/Desktop/Service/SensorHost | net48 전체 빌드, 아키텍처 시험, ViewModel의 플랫폼 I/O 경계 확인 |
| 운영 기능 | 미리보기·제외·일정·상한·중지·복구 보호·설치·제거 | 자동 시험과 설치된 제품의 연동 시험 |

## 검증 범위

자동 시험 44개 중 34개는 macOS/Linux에서도 실행하며, 10개는 Windows의 NTFS·서비스 경계·프로세스·PDH를 검증한다. Windows에서는 44개 모두 실행한다. 별도의 설치 연동 시험은 전용 가상 계정과 읽기 전용 센서 서비스 설치, 관리자 인증 Pipe, 실제 WPF 클라이언트 연결, 화면 PNG 생성, 제거를 수행한다.

처음 전체 통과한 검증은 [Windows와 core CI 실행](https://github.com/dmjeong/HardDisk-Manager/actions/runs/39551320886)에서 확인할 수 있다. 후속 변경의 결과와 실행 패키지는 [Actions](https://github.com/dmjeong/HardDisk-Manager/actions)에서 해당 커밋을 기준으로 확인한다.

## 설계 원안에서 조정한 부분

- UI 운영 권한은 관리자에게 제한한다. 일반 사용자 Viewer 모드는 제공하지 않는다.
- IPC는 길이가 제한된 요청/응답과 3초 상태 조회를 사용한다. 서버 push 이벤트 스트림은 제공하지 않는다.
- 감사 DB와 재생성 가능한 후보 DB를 분리한다. 성능 표본은 감사 DB에 배치 트랜잭션으로 저장한다.
- 성능 분 집계는 7일 보관한다. 원안의 90일 시간 단위 성능 집계는 구현 범위에 포함하지 않았다. 삭제·알람 이력은 별도 보관 설정을 따른다.
- 배포는 PowerShell 설치 패키지다. 코드 서명은 인증서를 지정하는 빌드 옵션으로 제공하며 기본 CI 패키지는 서명되지 않는다.
- 빈 폴더 복구는 원래 DACL로 충돌 없는 새 폴더를 생성한다. 파일은 제한된 임시 출력에 검증한 후 최종 이름으로 게시한다.
- Windows의 보안·공유·센서 제약으로 처리할 수 없는 대상은 스킵하거나 Unsupported 상태로 표시한다.

## 현장 인수 항목

실제 CPU/메인보드/HDD의 온도와 건강 정보, 운영 장비에서의 지속 I/O 이상, 72시간 연속 운전, 100만 파일·16볼륨의 처리량·자원 예산, DPI 150/200%는 대상 장비에서 추가로 확인해야 한다. 가상 Windows의 자동 시험을 이 실장비 검증으로 대신하지 않는다.
