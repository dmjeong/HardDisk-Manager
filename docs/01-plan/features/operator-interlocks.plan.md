# Operator options and interlocks plan

사용자가 승인한 네 가지 우선순위(최소 여유 RAM, 알림 방식/빈도, 요일/분 단위 실행 시간, 이력 용량 상한)를 모두 구현한다. 기존 리소스/장치 보호를 Interlock 상태로 제공하고 지정 프로세스 실행 중 정리 차단, 안정 회복 대기, 선택적 수동 Reset, 전이 이력을 추가한다.

기본 동작은 기존 정책과 호환되게 유지한다. CPU/온도/디스크 지연은 지속 시간 후 차단하고, 부족한 RAM은 즉시 차단한다. 차단된 채널의 측정이 사라졌다고 정상으로 취급하지 않는다. 수동 Reset/Resume는 현재 위험 조건과 필수 파일·감사·볼륨 보호를 우회하지 못한다.

파일 정리는 목표 용량에 대해서만 현재 폴더 완료를 기다리며 Interlock은 안전 지점에서 즉시 중단한다. 복구는 별도 작업으로 유지한다. 외부 신호/PLC 연동 필요 여부는 사용자에게 질문했으며 연결 요구사항 확인 전 외부 설비 프로토콜을 가정하지 않는다.
