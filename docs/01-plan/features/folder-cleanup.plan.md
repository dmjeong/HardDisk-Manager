# Folder cleanup plan

- 요청: 목표 용량에 도달해도 진행 중인 폴더를 정리한 뒤 중단한다.
- 관리 Root 바로 아래 폴더와 모든 하위 경로를 한 작업 단위로 취급한다. Root 바로 아래 파일은 각각 독립 단위다.
- 가장 오래된 삭제 대상이 있는 단위를 먼저 선택하고, 단위 안에서도 오래된 대상부터 처리한다.
- 현재 단위에서 목표에 도달하면 나머지 삭제 가능 대상과 비게 된 오래된 폴더를 처리한 뒤 종료한다.
- 최근/제외/복구 보호/잠김/지원하지 않는 파일은 유지한다. 용량 확보 조건 외의 취소·장치 이상·정책 변경·시간/항목/바이트 제한은 즉시 적용한다.
- Windows Service 작업자, 검증된 핸들 기반 삭제, 파일별 durable audit 및 1 GiB RAM cache를 유지한다. HDD 실측 없이 속도를 보장하지 않는다.
- 검증: 단위 정렬, 목표 도달 후 하위 폴더 정리, 다음 단위 보존, 복사 중 용량 변경, 단일 경로 재시도, 취소/장애, NTFS 통합 및 WPF 회귀 검증.
