# Recovery cache options plan

Settings에서 복구용 RAM 보관 한도를 수정하고 재시작 없이 적용한다. 기본값은 1024 MiB, 지원 범위는 1–16384 MiB이다. 예산 증가는 기존 복구본을 유지하고 필요할 때만 메모리를 할당한다. 축소 시 오래된 복구본부터 초과분을 퇴출하며 사용자에게 이를 안내한다.

삭제/미리보기/복구 작업 중에는 용량 변경을 거부하고 현재 작업 완료 또는 취소 후 적용한다. 다른 환경설정 저장은 기존 동작을 유지한다. 설정과 실제 캐시의 일치, 입력 범위, 영속 저장, 재시작 로드, 대시보드 갱신, FIFO/핀 보호/블록 풀 회수를 검증한다.

추가 옵션화 후보도 현재 UI 노출 여부와 운영 효용을 기준으로 정리하되, 이번 구현 범위는 복구 캐시 설정과 그 안내·검증으로 제한한다.
