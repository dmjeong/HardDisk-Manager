# Explorer Manager UI 개편 계획

목표: Linear 2026 UI 개편, Vercel Geist, Fluent 2의 정보 계층·간격·상태 표현을 WPF 관리 도구에 적용한다.

- 좌측 탐색과 일관된 페이지 헤더, 상태 푸터로 7개 화면을 구성한다.
- 개요: 실제 드라이브 용량 카드, 요약 수치, CPU 추이, 실행 기록.
- 정책: 기본/정리 기준/제외/고급 설정을 구분하고 저장·미리보기·삭제의 비중을 구분한다.
- 이력·복구·센서·알림·환경설정의 표, 빈 상태, 작업 설명을 통일한다.
- .NET Framework 4.8, 기존 서비스 프로토콜, MVVM, 자동 삭제 안전장치를 유지한다.
- Windows CI에서 전체 빌드/기존 테스트/새 표시 로직 테스트/디자인 타임 참조 해석/서비스 연동 및 모든 화면 렌더링을 검증한다.

완료 기준: 모든 화면의 시각 검토, 바인딩 오류 0건, main 푸시 및 CI 성공, 실행 패키지와 실제 스크린샷 제공.
