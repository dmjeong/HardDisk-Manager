# Desktop 기본 동작 복구 계획

2026-10-27. 사용자 보고: 종료 불가, Target volume 없음, 정책 입력 오류 해소 불가, CPU/디스크 데이터 없음.

목표는 F5/EXE 직접 실행과 설치 실행의 실제 동작을 복구하는 것이다. 기존 삭제 안전성과 .NET Framework4.8/MVVM은 유지한다.

1. X/Exit는 UI를 종료하고 별도 Hide to tray만 숨긴다. 관리자 재실행은 기존 UI를 종료한다.
2. 설치되지 않음/중지/권한/통신 실패를 구분하고 서비스 설치·시작을 UI에서 실행한다. 개발 빌드에도 설치에 필요한 실행 파일을 준비한다.
3. 서비스가 없을 때 로컬 읽기 전용 볼륨/CPU/RAM 실측을 표시하고 정책 실행·저장에는 연결 필요를 명시한다. 가짜 표본은 사용하지 않는다.
4. 정책 오류는 해당 필드에만 표시하고 수정할 내용을 요약한다. 자동 갱신/ComboBox가 초안을 지우지 않는다.
5. 일부 부가 조회나 성능 카운터 실패가 정상 Dashboard 전체를 지우지 않도록 격리한다.
6. 기존 시험 외에 서비스 없는 시작→설치/시작→볼륨/센서→잘못된 정책 수정/저장→정상 종료의 실제 Windows UI 흐름을 검증한다.
