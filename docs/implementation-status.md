# Explorer Manager 구현과 검증 현황

핵심 기능, WPF, Windows Service, SensorHost, 로컬 인증 IPC, SQLite 이력, 설치/제거, CI를 구현했습니다. 솔루션의 앱·라이브러리·시험을 모두 기존 .NET Framework 4.8 프로젝트로 통일하고 .NET 8 SDK 고정과 멀티타깃을 제거했습니다. 전체 자동 시험은 238개이며 Windows에서 모두 실행합니다. .NET SDK 경로를 비활성화한 빌드, WPF 디자인 시점 평가, 설치된 서비스와 WPF 8개 메뉴와 전송 내부 설정 화면45장의 실제 통신·렌더링·제거 연동 시험을 수행합니다. 최신 결과는 저장소 Actions의 해당 커밋을 기준으로 확인합니다.

UI는 좌측 탐색, 드라이브 카드, 용량 단위 표시, 구역별 정책 편집, 복구·알림 상세, 단위와 축이 있는 모니터링 차트로 개편했습니다. 공용 XAML 디자인 토큰과 컨트롤 템플릿을 사용하며 새로운 런타임 의존성은 없습니다. 미지원 측정값과 연결 실패를 구분하고 누락된 차트 표본은 선으로 연결하지 않습니다. 렌더 검사는 실제 서비스 연동 화면과 외부 작업을 차단한 예시 화면을 각각 1440×920 및 1120×720에서 캡처하고 바인딩 오류를 검사합니다.

폴더 단위 정리는 가장 오래된 대상이 있는 Root 바로 아래 폴더를 먼저 처리하고, 목표 공간 도달 후 현재 폴더의 삭제 가능 대상과 비게 된 오래된 하위 폴더까지 처리한 뒤 중단합니다. 취소·안전 제한은 즉시 우선 적용하며 정확한 경로 재시도는 주변 항목을 처리하지 않습니다. [검증 결과](04-report/folder-cleanup.report.md).

Settings에서 전역 복구 캐시를 1~16384 MiB로 지정하고 작업이 없을 때 재시작 없이 적용할 수 있습니다. 증가 시 기존 복구본을 유지하고 감소 시 초과분만 FIFO로 퇴출합니다. [검증 결과](04-report/cache-options.report.md). 승인한 최소 여유 RAM·알림 방식/빈도·요일/분 스케줄·이력 용량 옵션을 모두 구현했고, 상태와 차단 사유, 회복 대기, 수동 Reset, 실행 중 앱 차단과 재시작 후 래치를 제공하는 Interlocks를 추가했습니다. [검증 결과](04-report/operator-interlocks.report.md).

Transfers에서 기존 FTP/FTPS 서버로 지정 경로 이미지를 전송합니다. 영속 대기열, 자동 감지·재검색, 안정화와 native read lease, 검증된 APPE, SHA-256/read-back·게시 증빙, 삭제 직전 hash gate, 전송 Interlock과 MVVM 편집 화면을 추가했습니다. [구현 결과와 검증](04-report/image-transfer.report.md). TCP 전용 수신기는 기존 통신 명세 확보 후 추가할 수 있습니다.

대상은 로컬 NTFS 일반 파일입니다. 센서 지원 범위는 장비와 권한에 따라 달라집니다. 코드 서명 인증서, 실제 운영 장비의 센서 정확도, 72시간 연속 운전 및 100만 파일·16볼륨 현장 검증은 배포 환경에서 확인할 항목입니다.

설계와 달라진 배포 선택: 최초 버전의 UI와 Pipe 변경 명령은 관리자 운영자에게만 개방합니다. 일반 사용자 Viewer UI는 제공하지 않습니다. 성능 표본은 분 단위 7일을 유지하며 장기 시간 단위 집계는 후속 확장 항목입니다. 별도 MSI 대신 관리자 PowerShell 설치 패키지를 제공합니다.
